# SpacingScale

Container widths and the hero spine, drawn to relative scale. Documentation, not UI.

`max-w-measure` 900px · `max-w-cta` 1000px · `max-w-page` 1240px · `max-w-wide` 1400px ·
`max-w-shell` 1920px. The spine is 126px — the left edge every hero aligns its copy to,
available as `pl-spine`, `ml-spine` and friends.

## Props

| Prop | Type | Default | Meaning |
|---|---|---|---|
| `containers` | `boolean` | `true` | Show the container ramp. |

```jsx
<SpacingScale />
```
